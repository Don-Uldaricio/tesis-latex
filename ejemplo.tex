	\begin{resumenEs}
		Este es un modelo de documento que permite mostrar cómo utilizar el \textit{template} de tesis con el procesador de texto \LaTeX, específicamente su motor \texttt{pdflatex} para producir un \textsc{pdf} de calidad idealmente con la menor cantidad de dolores de cabeza por formato.

		La \textit{document class} ha sido construida pensando en que el formato sea el apropiado para la biblioteca de la Universidad de Santiago de Chile y que cualquier problema que ocasione el formato sea minimizado por el manejo de \LaTeX, en lugar de pelear con interfaces gráficas confusas.
	\end{resumenEs}
	
	\begin{resumenEn}
		This is a document model intended to show how to use the template for thesis writing with the text processor \LaTeX, specifically its \texttt{pdflatex} engine in order to produce quality \textsc{pdf} output, ideally with as less of a headache as possible when dealing with formatting.

		The document class has been built having in mind the required format for the library of the University of Santiago of Chile, and with the ideal that any problem that arises from formatting is minimized by the \LaTeX system handling, instead of struggling with confusing graphical user interfaces.
	\end{resumenEn}
